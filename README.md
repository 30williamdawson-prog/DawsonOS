# Dawson OS 🚀

Dawson OS is a lightweight, web-based operating system dashboard designed to run browser games and launch web searches from a single, clean interface.

## 🌟 Features

- **Game Library:** Quick-launch access to integrated web games.
- **Web Search Integration:** Built-in search bar powered by DuckDuckGo.
- **Live Clock:** Real-time clock interface built directly into the system header.
- **Responsive Interface:** Dark-themed dashboard built with HTML, CSS, and JavaScript.

## 🛠️ Built With

- **HTML5** - Structure and layout
- **CSS3** - Custom styling and dark mode UI
- **JavaScript (ES6)** - Interactive clock, URL navigation, and app loading
